# AI 文件整理助手 (Mac)

一个基于 AI 的 Mac 桌面客户端，帮助用户智能整理桌面、下载文件夹和指定文件夹中的文件。

## 功能特性

### 核心功能
- 🤖 AI 驱动的文件分析和整理方案生成
- 📁 支持整理桌面、下载文件夹和自定义目录
- 🎯 智能识别文件类型、项目和用途
- 📋 提供多套整理方案供选择
- ✏️ 支持方案微调（排除文件/目录、修改文件夹名）
- ⚡ 一键执行整理操作
- ↩️ 支持撤销最近一次整理

### 模型支持
- ✅ 本机本地模型 (http://127.0.0.1:1234)
- ✅ 局域网模型 (http://192.168.x.x:1234)
- ✅ 云端模型 API

### 安全特性
- 🛡️ 不删除文件，只移动和归档
- 🚫 不处理系统目录和隐藏目录
- 👁️ 执行前预览所有变更
- ↩️ 可撤销最近一次操作

## 页面清单

1. **首页** - 快速入口：检查桌面、整理下载文件夹、选择文件夹
2. **模型配置页** - 配置本地/局域网/云端模型连接
3. **扫描结果页** - 展示文件分析结果和问题摘要
4. **方案推荐页** - AI 生成 2-3 套整理方案
5. **方案微调页** - 调整方案细节（排除文件、修改目录名等）
6. **执行确认页** - 预览即将执行的变更
7. **执行中页面** - 显示执行进度
8. **结果页** - 展示整理结果和撤销选项
9. **历史记录页** - 查看最近整理任务

## 快速开始

### 环境要求
- macOS 10.15 或更高版本
- Node.js 18+
- npm 或 yarn

### 安装依赖
```bash
cd ai-file-organizer
npm install
```

### 开发模式运行
```bash
npm run dev
```

### 构建 DMG 安装包
```bash
./build.sh
# 或手动执行
npm run build
npm run dist:mac
```

构建完成后，DMG 文件位于 `release/` 目录。

## 使用说明

### 首次使用
1. 安装 DMG 文件
2. 打开应用
3. 进入模型配置页，填写模型信息
4. 点击"测试连接"确认可用
5. 保存配置后进入首页
6. 选择要整理的目录开始整理

### 支持的模型
- LM Studio (本地)
- Ollama (本地)
- 任何兼容 OpenAI API 格式的服务
